## English

# Oxygen - LibreOffice Theme

An Oxygen-inspired color theme for LibreOffice (Appearance), with light warm gray surfaces and a blue accent.

### Colors

| Item | Color |
|---|---|
| Accent / selected item | `#43ACE8` |
| Window and menu background | `#D6D2D0` |
| Button background | `#DFDCD9` |
| Text | `#221F1E` |
| Disabled text | `#898887` |
| Borders and separators | `#A09D9A` |

### Requirements

- **LibreOffice 26 or later.** The theme file format differs in 25.2, so this package does not work there.

### Installation

1. Download the latest `Oxygen.oxt` from the [Releases](../../releases) page.
2. In LibreOffice, go to **Tools > Extension Manager > Add...** and select the file.
3. Restart LibreOffice completely.

### Usage

Open **Tools > Options > LibreOffice > Appearance**, choose **Oxygen** from the theme list, and restart LibreOffice.

### Uninstallation

Select **Oxygen** in **Tools > Extension Manager** and click **Remove**. Switch to another theme first.

## Türkçe

# Oxygen - LibreOffice Teması

LibreOffice için Oxygen'den esinlenen, açık sıcak gri yüzeyler ve mavi vurgu rengi kullanan bir renk teması (Görünüm).

### Renkler

| Öğe | Renk |
|---|---|
| Vurgu / seçili öğe | `#43ACE8` |
| Pencere ve menü zemini | `#D6D2D0` |
| Düğme zemini | `#DFDCD9` |
| Metin | `#221F1E` |
| Pasif metin | `#898887` |
| Çerçeve ve ayırıcılar | `#A09D9A` |

### Gereksinimler

- **LibreOffice 26 veya üzeri.** Tema dosya biçimi 25.2'de farklı olduğu için bu paket orada çalışmaz.

### Kurulum

1. [Releases](../../releases) sayfasından en son `Oxygen.oxt` dosyasını indirin.
2. LibreOffice'te **Araçlar > Eklenti Yöneticisi > Ekle...** yolunu izleyip dosyayı seçin.
3. LibreOffice'i tamamen kapatıp yeniden açın.

### Kullanım

**Araçlar > Seçenekler > LibreOffice > Görünüm** sayfasında tema listesinden **Oxygen**'i seçin ve LibreOffice'i yeniden başlatın.

### Kaldırma

**Araçlar > Eklenti Yöneticisi** bölümünde **Oxygen**'i seçip **Kaldır** deyin. Önce başka bir tema seçin.
